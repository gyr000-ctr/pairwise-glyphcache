# pairwise-glyphcache

## 题面（可直接粘贴）

给字体渲染加按字节预算的字形位图缓存。约束：命中不重复解码；超预算按最近最少使用淘汰；总字节数始终不超过预算；禁用缓存时结果一致；并发取用安全；10 万次取用耗时不超过 1 秒。验收：python -m pytest tests -q -k glyph。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 并发取用
- 10 万次取用耗时
- 预算边界恰好耗尽
- 淘汰顺序确定性
- 大字形超预算处理

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线），通过不代表满分。
